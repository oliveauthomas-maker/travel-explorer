# 🌅 Travel Explorer

Guide de voyage familial — activités, événements, balades et friperies autour de vous.

## Stack
- React 18 + Vite
- API Anthropic (Claude Sonnet) + Web Search
- Géocodage : Photon (Komoot) pour l'autocomplétion, Nominatim pour le reverse geocoding

## Installation locale

```bash
npm install
cp .env.example .env
# Renseignez votre clé dans .env
npm run dev
```
